
# PaisaPlan – Expense and Budget Management System

## Project Description
PaisaPlan is a web-based Expense and Budget Management System that helps users manage their daily expenses and monthly budgets.

It allows users to record expenses, set budgets, track spending and monitor their remaining balance.

## Main Modules

1. **Dashboard:** Displays total expenses, monthly budget, remaining balance and expense charts.
2. **Expense Management:** Allows users to add, view, edit and delete expenses.
3. **Budget Management:** Allows users to create budgets and track their spending.

## Installation and Setup

### 1. Clone the repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Setup Backend
```bash
cd server
```

Install dependencies:
```bash
npm install
```

Create a `.env` file using `.env.example` and configure your MongoDB connection.

Start the backend:
```bash
npm run dev
```

### 3. Setup Frontend

Open another terminal:
```bash
cd client
```

Install dependencies:
```bash
npm install
```

Start the frontend:
```bash
npm run dev
```

Open http://localhost:5173 in your browser.

## Features

- Add and manage daily expenses.
- Categorize expenses.
- Set monthly budgets.
- Track remaining budget.
- View expense summaries and charts.
- Monitor monthly spending.

## Purpose

The main aim of this project is to help users manage their money effectively and develop better spending habits.
